# 🐍 AntiVenom Kodi Build

Welcome to the **AntiVenom Kodi Build** repository!

AntiVenom is an ultra-lightweight, high-performance Kodi 21 Omega build engineered specifically for Amazon Firestick, Android TV, and other low-RAM devices. 

## ⚡ The Anti-Bloat Manifesto
Traditional Kodi builds are often packed with 500MB+ of dead widgets, abandoned addons, and memory leaks that cause Firesticks to freeze. **AntiVenom** is the cure:
- **38MB Ultra-Lean Install**: Leaves your Firestick breathing room with near-zero storage footprint.
- **0.8s Boot Speed**: Loads immediately at a locked 60 FPS on Firestick Lite and 4K Max.
- **4 Dedicated Stream Hubs**: Curated hubs (Movies, TV Shows, Sports, Dual Search) using only tested, active scrapers.
- **Zero-Touch Auto-Updates**: Pulls scraper fixes seamlessly in the background without user intervention.

## 🚀 Installation (3 Simple Steps)

1. **Get Downloader App**: Search for "Downloader" in the Amazon Appstore.
2. **Enter URL**: Open Downloader and enter `https://tinyurl.com/antivenom-kodi` to download the zip file.
3. **Launch & Authenticate**: Open Kodi, "Install from zip file", and let AntiVenom set up automatically. Authorize your Real-Debrid account once and enjoy!
